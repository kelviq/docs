Connect Discord to get a message in a channel whenever a customer checks out, a subscription is cancelled, a payment fails, and more. Each message is colour-coded (green for good news, amber for warnings, red for cancellations and refunds) and links straight to the customer or order in your Kelviq dashboard.

You can connect as many channels as you like, each with its own set of events. For example, send sales to `#sales` and failed payments to `#billing`.

## Before you start

You need a **webhook URL** for the Discord channel you want to post to. It looks like `https://discord.com/api/webhooks/…`.

To create one, you need the **Manage Webhooks** permission on the Discord server:

1. In Discord, hover over the channel and click the gear icon (**Edit Channel**).
2. Open **Integrations** and click **Webhooks**, then **New Webhook**.
3. Optionally rename it (for example, `Kelviq`).
4. Click **Copy Webhook URL**.

Use a text channel. Webhooks on forum channels can't post to the channel directly. See Discord's guide to [webhooks](https://support.discord.com/hc/en-us/articles/228383668-Intro-to-Webhooks) for more help.

## Connect a Discord channel

1. Open **Settings → Integrations**.
2. On the **Discord** card, click **Configure Discord**.
3. Paste your **Discord webhook URL**.
4. Optionally, enter a **Channel name**, such as `#billing`. It's only used to label the connection in Kelviq.
5. Choose the **Events to send**. These are selected by default:
   - Checkout completed
   - Subscription created
   - Subscription cancelled
   - Invoice payment failed
   - Refund created
6. Click **Connect Discord**.

Kelviq posts a "Kelviq is connected" message to the channel to confirm the URL works. From then on, every selected event is posted to that channel.

<Note>
  Connections are separate for sandbox and live. If you connect Discord while in [sandbox mode](/guides/sandbox), only sandbox events are sent to that channel. Switch to live mode and connect again to get live events.
</Note>

Messages never ping anyone: Kelviq turns off `@everyone`, `@here`, role and user mentions, even if a customer's name contains one.

## Manage a connection

Open **Settings → Integrations → Configure Discord** to see your connected channels. For each one you can:

- **Send test**: post a test message to check the channel is still reachable.
- **Edit events**: change which events are posted, then click **Save events**.
- **Disconnect**: stop sending messages to that channel.

To post to another channel, click **Add another channel**.

Each Discord connection is a Kelviq webhook endpoint, so it also appears under **Settings → Webhooks**, named `Discord: <channel name>`. There you can see every delivery and resend one that failed.

## Events you can send

You can send any [webhook event](/guides/webhooks#event-types) to Discord:

| Category | Events |
| --- | --- |
| Checkout | Checkout completed |
| Customers | Customer created, Customer updated |
| Orders | Order created, Order updated, Order refunded |
| Subscriptions | Subscription created, updated, paused, resumed, cancelled, plan changed, trial will end |
| Invoices | Invoice created, Invoice paid, Invoice payment failed |
| Refunds | Refund created, Refund updated |
| Features | Feature usage alert |
| Payment methods | Payment method created, updated, deleted |

## Troubleshooting

If messages stop arriving, open **Configure Discord** and click **Send test**. The error tells you what's wrong:

| Error | What to do |
| --- | --- |
| This Discord webhook was deleted | Create a new webhook in the channel settings, then disconnect and connect again with the new URL. |
| This Discord webhook URL is not valid | Copy the URL from Discord again and reconnect. |
| The Discord channel for this webhook no longer exists | Create a webhook in another channel and reconnect. |
| This webhook belongs to a forum channel | Create the webhook on a text channel instead. |

If Discord is briefly unavailable or rate-limits the channel, Kelviq retries the delivery automatically, so you won't miss the message.
