Every example is a live sandbox checkout. To try one, pay with the test card `4242 4242 4242 4242`, any future expiry date, and any CVC.

The examples use the default look. You can change the logo, colors, and which sections appear in [Checkout design](/checkout/checkout-design).

## Light and dark mode

By default, checkout follows the light or dark setting on the customer's device, and the customer can switch it from the bottom-left corner. To always show light or dark, change the mode in [Checkout design](/checkout/checkout-design#light-and-dark-mode). The other screenshots on this page match the theme you're reading in.

## Included usage with overage

The Context API Developer plan costs \$19 a month, includes 7,500 credits, and charges \$2.20 per 1,000 credits after that. Checkout charges the \$19 base fee. Overage is [billed at the end of each monthly period](/product-catalog/usage-based-billing) from the usage your backend reports.

  A single-plan checkout doesn't show the overage rate. Put it in the plan description and link to the [plan picker](#plan-picker) instead, which shows each plan's description, or state the rate on your pricing page.

## Discount applied

A link can carry a discount code, so the customer doesn't have to type it. Checkout fills in the code and shows the discount and the reduced total. Here the link adds `discount_code=VOICE50`, which takes 50% off the first month of Creator. Use it in campaign emails and partner links.

## Per-seat plan

A per-seat plan charges for each seat the customer buys. The seat count comes from your app, so this checkout is created with the [Checkout API](/api-reference/checkout/create-a-checkout-session) rather than a static link. This example offers TeamBoard Basic and Business for 5 seats, with Business selected: \$16 a seat, \$80 a month, after a 14-day trial.

<Frame>
  <img className="block dark:hidden" src="/images/checkout-examples/per-seat-light.webp" alt="TeamBoard checkout with Basic and Business plans, Business selected with 5 seats at $80 a month" />
  <img className="hidden dark:block" src="/images/checkout-examples/per-seat-dark.webp" alt="TeamBoard checkout with Basic and Business plans, Business selected with 5 seats at $80 a month" />
</Frame>

```json
{
  "planIdentifier": "tb-business",
  "plansEnabled": "tb-basic,tb-business",
  "chargePeriod": "MONTHLY",
  "features": [{ "identifier": "tb-seats", "quantity": 5 }],
  "successUrl": "https://example.com/welcome"
}
```

The response has a `checkoutUrl` to send the customer to. See [Seat-based pricing](/product-catalog/seat-based-pricing) for how to set up the plan.
