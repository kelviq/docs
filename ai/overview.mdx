## The quick version

1. Open **Settings → Set up with AI** in the dashboard.
2. Copy the keys block into your project's `.env.local`.
3. Copy the prompt and paste it into your agent as the first message.

Your agent can build and test everything with sandbox keys, then you go live when it's ready. You can also set it up directly in production. Either way, business verification and your keys stay with you.

## Give your agent the docs

Point your agent at the Kelviq docs so it answers from them instead of guessing.

| Resource | Use it for |
| --- | --- |
| [`llms.txt`](https://docs.kelviq.com/llms.txt) | An index of every docs page, in Markdown |
| [`llms-full.txt`](https://docs.kelviq.com/llms-full.txt) | All the docs in one file |
| `https://docs.kelviq.com/mcp` | Docs MCP server: search and read the docs from any MCP client |

In Claude Code, add the docs MCP server with:

```bash
claude mcp add --transport http kelviq-docs https://docs.kelviq.com/mcp
```
